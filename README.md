# Smart Canteen Token System

## Project Description
The Smart Canteen Token System is a JavaFX desktop application developed using Java, JDBC, and MySQL. It helps manage food orders, generate tokens, and view order status and history.

## Technologies Used
- Java
- JavaFX
- JDBC
- MySQL
- Maven
- Git and GitHub

## Main Features
- User registration and login
- Food menu display
- Food order placement
- Token generation and display
- Order status viewing
- Order history
- Queue viewing

## Requirements
- Compatible Java JDK
- Maven
- MySQL Server
- JavaFX dependencies configured in pom.xml

## Database Setup
Create or import the smart_canteen database and its required tables in MySQL. Configure the local database connection in DatabaseConnection.java.

## Run the Application
Open a terminal in the project root folder and execute:

mvn javafx:run
